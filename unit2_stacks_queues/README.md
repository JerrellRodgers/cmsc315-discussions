I completed the Stack and Queue classes using Python.

For the stack, I used a Python list to demonstrate Last In, First Out (LIFO) behavior. I created a scenario involving Zoro's swords from One Piece. Four swords were added to the stack, and the program demonstrated how the most recently added sword was removed first.

For the queue, I used collections.deque to demonstrate First In, First Out (FIFO) behavior. I created a scenario involving Sanji serving food to the Straw Hat Pirates. Four pirates joined the line, and the program served them in the same order they arrived.

I also tested several edge cases, including removing items from empty stacks and queues, viewing empty collections, and removing the only item from a collection.
